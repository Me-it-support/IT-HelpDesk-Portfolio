Lab-11 — Dell Laptop System Troubleshooting

Overview

Diagnosed and resolved an intermittent system freezing issue on a Dell laptop following Windows updates and restarts.

System Specifications

- Device: Dell Laptop
- RAM: 4 GB
- Storage: 512 GB HDD
- OS: Windows 10

Troubleshooting Performed

- Windows Recovery Environment (WinRE) investigation.
- Disk and partition inspection using DiskPart.
- Offline system integrity scan using SFC.
- Windows Update recovery assessment.
- System Restore investigation.
- Event Viewer and Reliability Monitor analysis.
- Startup configuration optimization.
- System restart and performance monitoring.

Results

- Completed system integrity checks.
- Successfully restored normal system operation.
- Optimized startup configuration.
- No further freezing observed during the monitoring period.

Final Status

Issue Resolved — Stability Confirmed

Technical Skills

Windows Troubleshooting · WinRE · DiskPart · SFC · Event Viewer · Reliability Monitor · Startup Optimization · Performance Monitoring
